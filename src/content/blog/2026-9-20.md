#### 一、网页/软件APP

网页（web）本质上也是软件的一种，只是在运行环境、安装、权限等有所差别

<br>

|层面|网页|APP|
|:---:|:---:|:---:|
<br>
|运行环境|浏览器|设备本地|
<br>
|安装|无需安装直接输入<br>网址即可使用|需要根据不同操作<br>系统进行下载安装|
<br>
|权限|权限较低<br>无法直接访问设备|可以直接访问本地<br>使用本地文件|
<br>
|......|......|......|

<br>

#### 二、软件主要是由两方面构成：前端与后端
<br>

##### 1.前端
简单来说，我们在软件里看到的一切，界面与交互体验，就称为前端，你看到的软件的页面，一个个商品、视频的展示，一个个滑动、点击、跳转，都是前端的内容\
[前端的本质](https://chat.deepseek.com/share/00r7okg3srnt9nilnd "deepseek的看法")

<br>

##### 2.后端
简单来说，就是在用户看不见的地方，管数据、管规则、管安全、管稳定，让整个系统能正确、可靠地跑起来，如你登录的游戏账号，就是在后端的数据库存着\
[后端的本质](https://chat.deepseek.com/share/r81dk2an3vh1iwiq4t "deepseek的看法")

<br>

#### 三、前后端的实现方式：代码编写
代码，就是命令翻译后的内容\
比如我接下来写的代码
```cpp
//Hello world代码编写

#include<iostream>
using namespace std;

int main(){
    cout << "Hello world" << endl;
    return 0;
}
```
它的命令就是（换行是为了美观，其实分号就代表一行结束了）：\
第1行：//代表忽略我这一行的内容\
第3行：#include就是引用一个文件库，可以直接用那个文件里的东西\
第4行：就是替换std这个关键字\
第6行：主函数\
第7行：打印一个"Hello world"字符串\
第8行：结束

##### 我们的代码编写工具，就是把代码转为机器听得懂的命令，然后机器就会猛猛听你话干活。你的代码逻辑、算法的不断叠加，最后就实现了软件的一个个功能
