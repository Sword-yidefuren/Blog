##### 一、代码块编写
ESC下面的三个下引号再加上所写语言（小写）
```c++
// C++代码
#include <iostream>
using namespace std;

int main(){
    cout << "Hello, world!" << endl;
    return 0;
}
```
<br>

##### 二、表格
|x|x|x|
有几列就加几个|:---:|\
|:---|表示左对齐\
|:---:|表示居中对齐\
|---:|表示右对齐\

|姓名|年级|专业|
|:---:|:---:|:---:|
|锐哥|25级|计算机科学与技术|
|锐弟|29级|不知道|
<br>

##### 三、脚注（[^x]然后在下面解释[^x]即可）


页面下方和页面右上角的小猫叫做GitHub[^GitHub]
<br>

##### 四、链接（[x]后面加(网址)即可，在括号里加"补充内容"，鼠标移到，即可显示补充内容）
[百度](baidu.com "一个搜索引擎")\
[bilibili](bilibili.com "视频网站")\
[DeepSeek](deepseek.com "AI")

<br>

##### 五、四基础上，可以将同一个网址统一管理，多次引用更方便（`[x]`加上`[id]`，然后在后面解释`[x][id]`即可，每次用只需要`[x]`加上`[id]`）

[bilibili][id]

[id]: bilibili.com "一个视频网站"
